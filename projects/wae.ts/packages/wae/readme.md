# `@wae/wae`

WAE meta CLI (sole bin: `wae`). Built on `@wae/commander` for scaffolding, building, staging native npm addons, and publishing.

## Commands

```bash
wae new <name> [--with-gui] [--out <dir>]
wae build --project <dir> --package <name>
wae dist --project <dir> --package <name> --out <dir> --file <name>
wae publish --dir <path> [--dir <path>...] [--execute]
```

Product strings live in this package's `locales/`. Framework chrome comes from `@wae/commander`.

## Upgrading from `0.0.4`

`0.0.4` could exit `0` without doing any work when `wae build` was launched through a package-manager symlink. `0.0.5` compares resolved entry paths, and an entry that cannot be resolved to its own module now fails with a non-zero exit code and a diagnostic instead of reporting success.

Scaffolds generated by `0.0.5` pin `@wae/wae` and `@wae/commander` to the exact release that produced them, so an older project upgrades by changing both dependencies and reinstalling, or by running `wae new` again.

## Develop

```bash
pnpm --filter @wae/wae build

pnpm exec wae --help
```
